## The ordering problem, and why it is not "just merge them"

`state/DASHBOARD.md` embeds a timestamp and the branch's own last-ten-commits, so
it is **different on every branch by construction**. Every merge writes a new one
to `master`, which means a branch updated _before_ that merge conflicts _after_
it. The only conflict-free procedure is strictly serial:

```
merge #N  ->  fold the new master into #N+1  ->  merge #N+1  ->  ...
```

Measured across the whole queue: zero code conflicts. Every single conflict, at
every step, was `state/DASHBOARD.md` (and once the session file). Resolving them
is `git checkout --theirs` followed by the post-commit hook regenerating the file.

Order taken: **#201 → #199 → #200 → #202 → #203 → #204**, then the release #195.

## Two mistakes made here

1. **`gh pr merge 199 --delete-branch` closed #200.** #200 was stacked on that
   branch, and deleting a base branch closes its dependents. Recovered by
   recreating the branch at its exact commit, reopening the PR, retargeting to
   `master`, then deleting the temporary branch. Do not delete a branch another
   open PR is based on.
2. **A commit landed on `master`** — `.github/codeql-config.yml`. It was never
   pushed; recovered with `git cherry-pick` onto the right branch and
   `git reset --hard origin/master`. The branch was printed by
   `git branch --show-current` one command earlier and read past.

## CodeQL blocked #200 with two high alerts

The alerts were the **planted defects** in `fixtures/insecure-app/app.js` (a
disabled TLS check, an RSA-1024 key). Those defects exist so the CodeQL adapter's
end-to-end test has something real to find — so the test and the gate pulled in
opposite directions: the only way to keep the test meaningful was to fail the
scan.

Fixed structurally in `.github/codeql-config.yml`: `paths-ignore` now includes
`fixtures/**`, which is the same rule the repository already applies in
`eslint.config.mjs` and `.usa.yaml`. `examples/demo-app` was already excluded;
the scanner fixtures arrived later and were never added.
